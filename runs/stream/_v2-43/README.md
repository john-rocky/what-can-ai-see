The oblique-view run at the clips' NATIVE 4:3, before the aspect ratio was matched
to the overhead corpus.

The overhead clips are 16:9 (cropped from a 4:3 source by the original pipeline);
second_view.py wrote the oblique ones at native 4:3. Every model in the catalog
stretches its input to a square canvas (F1), so a 2x2 sheet of 16:9 panels is
squashed harder than one of 4:3 panels — aspect is not a free variable and these
two runs were not comparable on viewpoint alone.

Kept because the pair of runs now measures the aspect effect directly: same
episodes, same events, same model, one framing change.
